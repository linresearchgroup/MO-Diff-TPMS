# Eight stored augmentation training rows

`inputs.csv` contains the complete six constituent moduli and saved t1/t2, the saved storage/loss labels, and one-based Excel row identifiers in the actual augmented training and combined databases. `results.csv` retains all 16 component results, including the large errors; `summary.csv` retains the statistics. Units are MPa. Label AE is |Saved label - Calculated|, and label APE is 100 times that AE divided by |Calculated|.

The eight rows were fixed before calculation using deterministic maximin coverage in min–max-normalized (t1, t2, saved storage label, saved loss label), seeded at the lowest storage label. The original cohort was reconciled after four-decimal rounding of the six material columns: 16,471 original records plus 25,098 added records; 19,834 added records are in the downstream training subset. This identifies actual stored added training rows, not newly generated RNN examples. The public `data/combined_augmented_train.xlsx` and `data/combined_augmented_all_data.xlsx` match the source files for the row identifiers; the original cohort is under `../reference_data/TrainingData.xlsx`.

Storage/loss label APE medians are 3.34%/16.72%, and maxima are 83.14%/414.58%. This is a finite coverage check, not a random estimate of whole-database error and not an augmentation ablation. Six pairs lie outside the nominal bounds and three have t1 > t2; saved inputs were not clipped or sorted. The actual phase implementation still defines their material assignments.

The original eight calculation records are in `../logs/augmentation_original/`. Later diagnostic replays of A1, A3, A4 and A8 reproduce their stored moduli: all 24 load-case solves have flag 0, maximum true relative residual 9.9772e-7, and 105.5–205.5 BiCGSTAB iterations at tolerance 1e-6. Those residual histories are in `../logs/diagnostic_replays/`. The other four original calculations lack recorded exit flags/residual histories; no such historical convergence evidence is claimed. A1 is entirely phase 1 and A3 entirely phase 2. Large label discrepancies remain after the converged replays.

The saved database has no per-row generating-window/perturbation map. This check neither certifies every historical label–geometry assignment nor validates all synthetic labels. Upstream normalization exposure and label use in model-weight fitting are separate questions. The high-stiffness evaluation contains no BiLSTM-added rows and is separate evidence.
