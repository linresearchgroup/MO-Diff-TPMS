# Source and attribution

These retained research sources keep their original author, copyright and citation headers. No new blanket license, including MIT, is assigned, and no wholesale authorship reassignment is made. No explicit no-redistribution clause was found in the selected supplied source files. Applicable original terms and attribution continue to apply.

Interpolation sources retain the PolyTop reference to C. Talischi, G. H. Paulino, A. Pereira and I. F. M. Menezes, DOI 10.1007/s00158-011-0696-x. Domain utilities retain the PolyMesher reference where present, DOI 10.1007/s00158-011-0706-z. Other retained identifiers include HomogVisco3D and PolyTop3D.

`Homog_TPMS_Visco3.m` and `Function_Files/` are retained numerical sources. `entrypoints/` contains organized copies with relative paths and output protection; the manifest distinguishes these copies. `run_fixed_inputs.m` is a publication/revision wrapper, not original training or generation code. `diagnostics/PeriodicFEA_3D.m` is the diagnostic overlay used by completed revision checks: it captures the existing BiCGSTAB return values and residuals without changing the numerical call arguments. The accompanying patch identifies those additions.

Source hashes and project-relative origins are listed in `verification/round2/SOURCE_MANIFEST.json`. Paths in published logs/provenance are redacted or project-relative; reported numerical values are not changed. Retained numerical sources support the stated fixed-input calculations, not exact reproduction of every historical model-training or augmentation operation.
